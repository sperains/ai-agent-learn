# 建立长期学习系统

## 本次目标

为中高级 AI Agent 工程进修建立可以长期接续的课程、实验、记录和复盘结构。

## 已完成

- 建立中高级岗位导向的八阶段学习路线。
- 建立能力矩阵和接续规则。
- 建立每课模板与实验规范。
- 预留实验目录，后续从手写 Agent Loop 开始。

## 当前结论

学习目标不是积累框架用法，而是形成“设计—实现—测试—观测—复盘”的完整工程能力。

学习者目前是 AI Agent 初学者，因此路线需要从大模型、接口、消息、工具和最小代码实验开始，不能直接假设已经掌握 Agent 运行时、RAG 或生产架构。

## 下一步

先完成入门前置课：理解模型请求与响应，再创建第一个最小实验；后续逐步实现工具调用循环，并覆盖正常返回、工具失败和停止条件。
