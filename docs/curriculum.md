# 前十二课详细课程

前十二课完成“从零到手写最小 Agent”的闭环。每课建议 60～120 分钟；未达到验收标准时允许拆成多次学习，不为了赶进度跳课。

后续课程不是留空临时发挥。全部阶段的课程编号与能力骨架见 [curriculum-map.md](curriculum-map.md)，每一课都必须通过 [curriculum-governance.md](curriculum-governance.md) 中相同的质量门禁。前十二课先详细展开，是为了根据真实学习反馈校准后续难度，而不是降低后续课程的规划程度。

| 课次 | 主题 | 核心问题 | 产出 | 前置 |
|---|---|---|---|---|
| 01 | 一次模型调用发生了什么 | 程序如何把消息交给模型并收到结果？ | 可替换的模型接口和固定响应实验 | 无 |
| 02 | 消息、角色与上下文 | 模型本轮究竟能看到什么？ | 消息序列实验和事件链说明 | 01 |
| 03 | Token、上下文窗口与费用 | 为什么上下文不能无限增长？ | 简单 Token 预算实验 | 02 |
| 04 | Prompt 与结构化输出 | 如何让概率输出进入确定程序？ | JSON 输出校验与失败样例 | 02 |
| 05 | HTTP、API 与错误 | 模型请求会怎样超时、限流和失败？ | 模拟超时与错误分类测试 | 01 |
| 06 | 工具调用的本质 | 模型“调用工具”时实际输出了什么？ | 一个只读计算工具 | 04 |
| 07 | 工具注册与参数校验 | 如何拒绝模型生成的错误参数？ | 工具注册表和参数验证测试 | 06 |
| 08 | Observation 回传 | 工具结果怎样影响模型下一步？ | 两轮工具调用记录 | 06～07 |
| 09 | 手写最小 Agent Loop | 谁控制“思考—行动—观察”循环？ | 不依赖编排框架的循环 | 08 |
| 10 | 停止条件与循环保护 | Agent 什么时候结束或被强制终止？ | 最大步数和终止原因测试 | 09 |
| 11 | 工具失败、重试与降级 | 错误应该由程序还是模型处理？ | 可重试与不可重试错误实验 | 09～10 |
| 12 | 第一阶段综合验收 | 是否真正理解 Agent 的最小运行时？ | 讲解、代码、测试和复盘证据包 | 01～11 |

## 第一阶段证据包

- 一张完整事件链图或文字说明；
- 一个可运行的最小 Agent Loop；
- 正常、参数错误、工具失败、超过步数四类测试；
- 一篇复盘，说明普通聊天、固定工作流和 Agent 的边界；
- 一次不看笔记的口头或书面讲解。

后续课程在阶段验收后再细化，避免现在制造大量可能失效的框架教程。
