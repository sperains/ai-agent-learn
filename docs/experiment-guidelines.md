# 实验规范

每个实验必须回答四个问题：

1. 它解决了什么 Agent 工程问题？
2. 输入、状态、工具调用和输出分别是什么？
3. 哪些地方可能失败，失败后如何恢复？
4. 用什么测试或指标证明它有效？

实验应保持最小化：一次只引入一个新概念；先手写可理解版本，再引入框架；代码、测试和说明同步完成。外部模型或服务不可用时，优先使用可替换的适配层和固定测试数据，保证学习不被服务波动打断。

## 目录约定

```text
experiments/lesson-NN-topic/
├── README.md
├── src/
├── tests/
└── fixtures/
```

- `README.md` 记录目标、事件链、运行方式和失败结论；
- `src/` 只放本课需要的最小实现；
- `tests/` 保存正常、边界和失败测试；
- `fixtures/` 保存固定模型响应等可重复输入；
- 命名使用课次，保证日志、进度和代码可以互相链接。

## 可复现要求

所有实验默认使用 `uv run pytest` 验证。需要真实模型时必须同时保留固定响应路径；不得提交真实密钥、个人数据或无法公开的业务资料。
