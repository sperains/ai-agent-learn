# 能力验收与证据

## 状态定义

| 状态 | 含义 |
|---|---|
| 未开始 | 尚未进入该能力 |
| 学习中 | 能跟随示例完成，但不能独立处理变化 |
| 可独立完成 | 不照抄示例也能完成同类任务并解释原因 |
| 已通过回归 | 一周后完成变体实验，旧测试仍然通过 |
| 需要复习 | 无法解释、无法复现或回归失败 |

## 有效证据

一个能力只有同时具备以下证据，才能标记为“可独立完成”：

1. 课程笔记：能用自己的语言解释语义边界和事件链。
2. 可运行实验：代码可以在干净环境复现。
3. 自动化测试：包含正常路径、边界和至少一个失败场景。
4. 学习复盘：记录误解、取舍、遗留问题和下一步。

“看过文章”“跟着视频敲过”“代码运行过一次”不能单独作为掌握证据。

## 阶段准入

进入下一阶段前必须满足：

- 本阶段证据包完整；
- 一周回归检查通过；
- 能回答路线中该阶段的完成标准；
- 综合项目已吸收本阶段能力；
- 未解决问题已记录，并明确是否阻塞后续学习。

## 岗位证据映射

| 岗位能力 | 仓库证据 |
|---|---|
| Agent 架构 | 运行时实验、状态图、架构决策记录 |
| 工具安全 | 参数校验、权限、幂等和审批测试 |
| 上下文工程 | 上下文预算、压缩和恢复实验 |
| RAG 与记忆 | 检索评测集、失败归因报告 |
| 评测与观测 | 回归报告、Trace、延迟与成本数据 |
| 生产交付 | 部署说明、故障演练、审计和回滚方案 |
