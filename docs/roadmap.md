# 学习路线

路线分为“入门基础、核心能力、工程进阶、岗位进修”四层。当前从第一层开始，不跳过必要基础。

## 入门基础：理解 Agent 所处的世界

了解人工智能、机器学习、大语言模型、Token、上下文、Prompt、API、JSON 和基本的客户端—服务端关系；补齐 Python、命令行、Git、HTTP、异步编程和测试的最低使用能力。

完成标准：能写一个普通的模型对话程序，并能解释请求、响应、消息和错误。

## 阶段一：理解并手写 Agent 循环

理解模型消息、工具调用、循环、停止条件、结构化输出和错误处理；手写最小 Agent Loop。

完成标准：能说明普通聊天和 Agent 的区别，并手写一个不依赖编排框架的最小 Agent Loop。

## 阶段二：工具与任务执行

实现工具注册、参数校验、超时、重试、幂等、权限、审批和副作用隔离。

完成标准：至少实现一个只读工具和一个有副作用工具；参数错误可解释、重复执行不产生重复副作用、高风险操作必须经过确认。

## 阶段三：状态与上下文工程

区分会话历史、任务状态、短期记忆、长期记忆和外部知识；实现压缩、预算和恢复。

完成标准：任务中断后可从持久化状态恢复；能说明每类上下文的来源、生命周期、可信度和 Token 成本。

## 阶段四：RAG 与记忆系统

完成文档解析、切分、召回、重排、引用、记忆写入和检索质量评估。

完成标准：使用固定问题集分别测量检索与回答质量，并能把失败归因到解析、召回、重排、上下文或生成环节。

## 阶段五：工作流与多 Agent

比较固定工作流、单 Agent 和多 Agent；实现路由、并发、状态机、人工介入和失败恢复。

完成标准：对同一任务给出三种方案的选择依据；工作流支持暂停、恢复、超时和部分失败，且多 Agent 只在有量化收益时引入。

## 阶段六：评测与可观测性

建立任务数据集、回归测试、轨迹检查、质量指标、Trace、延迟、Token 和成本统计。

完成标准：每次模型、提示词或检索策略调整都能执行同一套回归评测，并输出质量、延迟与成本变化。

## 阶段七：生产化与系统设计

加入多租户、鉴权、数据隔离、限流、降级、审计、部署、灰度和故障处理。

完成标准：能够完成一次生产架构评审，说明数据边界、权限模型、容量假设、故障策略、回滚方案和成本预算。

## 阶段八：综合项目与面试

完成一个可解释、可评测、可恢复的企业级 Agent 平台，并进行架构设计和故障排查演练。

完成标准：项目可复现运行，核心路径有自动化测试和评测报告；能够在不看稿的情况下完成架构讲解、设计取舍和故障复盘。

每阶段完成标准：能运行、能测试、能解释、能定位失败、能记录取舍。入门阶段不追求一次掌握全部内容，而是每次只引入一个新概念。
