# 复习与接续节奏

## 每次开始前（5 分钟）

1. 阅读 `docs/progress.md`。
2. 阅读最近一篇学习日志。
3. 用自己的话复述上一课的核心事件链。
4. 从“唯一下一步”继续，不临时扩展新主题。

## 每次结束前（10 分钟）

1. 保存代码、测试和失败样例。
2. 按课程模板完成复盘。
3. 更新能力状态和证据链接。
4. 只指定一个下一步。
5. 登记次日与一周后的复习日期。

## 次日复习

不看笔记解释三个问题：它解决什么问题、事件链如何流动、最容易在哪里失败。解释不清时将能力标记为“需要复习”。

## 一周回归

完成一个与原实验不同的变体，运行旧测试和新测试。通过后才能标记“已通过回归”。

## 每四课复盘

- 检查是否只会正常路径；
- 清理重复或失效笔记；
- 统计仍无法独立解释的概念；
- 将已掌握能力集成到贯穿式项目；
- 调整后四课的难度，不随意改变长期目标。
- 按教学质量契约评分，确认下一批课程仍满足相同标准。

## 每阶段复盘

执行阶段证据包验收，记录质量、耗时、主要误区和下一阶段风险。阶段未通过时补证据，不重复从头学习全部内容。

## 每季度校准

重新抽样真实岗位要求和主流官方文档，只调整可能变化的工具、框架和岗位侧重点；基础原理与历史实验保留。
