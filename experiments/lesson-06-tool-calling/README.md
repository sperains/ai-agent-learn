## 目标

完成本课后，能够说明模型工具调用只是结构化意图，真正的工具执行权仍在应用程序。

## 概念边界

模型返回的 `ToolCall` 包含工具名和参数，不能直接等同于工具已被执行。应用程序接收这个意图后，决定是否支持该工具，再执行受允许的操作。

本课只实现只读的加法工具。未知工具被明确拒绝，不能因为模型提出请求就自动执行。参数类型尚未校验，下一课会在执行前拒绝错误参数。

## 核心事件链

```text
模型返回工具调用文本
  → parse_tool_call 解析为 ToolCall 意图
  → 应用检查工具名
  → 支持 add：执行加法并返回结果
  → 不支持的工具：抛出错误，不执行任何操作
```
