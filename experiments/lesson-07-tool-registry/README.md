## 目标

完成本课后，能够用注册表限制可调用工具，并在执行前拒绝未知、缺失或类型错误的参数。

## 概念边界

工具注册表是应用维护的白名单。模型输出的工具名只能匹配已注册处理函数，不能直接映射为任意程序函数或命令。

参数检查发生在实际工具执行前。加法工具要求 `left` 和 `right` 均存在且为数字。布尔值即使在 Python 中能参与加法，也不符合数值参数的语义，必须拒绝。

## 核心事件链

```text
模型返回 ToolCall
  → 注册表查找工具名
  → 未注册：拒绝执行
  → 已注册：检查必填参数
  → 检查参数类型与语义
  → 参数有效：执行工具并返回结果
```

业务实现位于 [src/main.py](src/main.py)，测试位于 [tests/test_lesson_07_tool_registry.py](tests/test_lesson_07_tool_registry.py)。

- 未注册工具被拒绝；
- 缺少 `right` 参数被拒绝；
- 字符串和布尔值等非数字参数被拒绝。
