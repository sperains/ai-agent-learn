- 日期：2026-09-04

## 目标

完成本课后，能够将工具成功或失败的结果作为 `tool` 消息回传给模型，使模型决定下一步。

## 核心事件链

```text
模型请求工具 → 应用执行 → 工具结果作为 tool 消息回传 → 模型生成下一步回答
```

工具结果可能只是中间事实。模型需要看到它，才能解释结果、选择后续工具或根据失败调整请求。应用仍负责执行权限和重试限制。

## 实验与验证

业务实现位于 [src/main.py](src/main.py)，测试位于 [tests/test_lesson_08_observation.py](tests/test_lesson_08_observation.py)。

- 成功工具结果以 `tool` 消息回传后才取得最终回答；
- 未知工具失败时停止在第一轮，不发起第二轮模型调用；
- 2026-09-04 完整测试结果为 `30 passed`。
